# Echoes from This Land website

This version uses plain HTML, CSS, and JavaScript. It does not require Vue, Peggy, npm, or a build process, and it can be published directly with GitHub Pages.

## Updating the current GitHub Pages repository

Copy these files into the root of the existing repository:

- `index.html`
- `about.html`
- `artists.html`
- `exhibitions.html`
- `resources.html`
- `style.css`
- `script.js`
- `CNAME`

Keep the current repository's image folders. The uploaded ZIP was an older three-page version and did not include all of the exhibition images used by the current public site. The revised exhibition page therefore points to the existing images at `echoesfromthisland.ca`.

The home page is designed to remain within the browser viewport without page scrolling. All interior pages use normal scrolling.
